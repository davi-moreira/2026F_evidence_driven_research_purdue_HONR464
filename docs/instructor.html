Instructor Material

Instructor notebooks (with solutions) and session guides, one row per Studio, each with the week’s required EDR|AI chapters — the same reading students see on Material and Schedule, generated from the book’s own manifest so the three surfaces cannot drift apart. Both live in the private repository davi-moreira/2026F_evidence_driven_research_purdue_HONR464_instructor — opening them requires being signed in to GitHub as the instructor. One-time Colab setup: open colab.research.google.com, choose the GitHub tab, and check “Include private repos” when authorizing.
